# Start today's lesson

## Instructor: next five minutes

1. Open [Week 1 instructor notes](weeks/week-01/INSTRUCTOR.md).
2. Put [Week 1 agenda](weeks/week-01/README.md) on screen.
3. Send learners [Setup](SETUP.md) and [the bootstrap prompt](prompts/00-bootstrap.md).
4. If setup is incomplete, pair on the instructor's machine and use the [fallback interview](prompts/01-deep-interview.md#fallback-without-the-skill).
5. Keep [the sample brief](materials/demo-brief.md) ready if the interview or network stalls.

## Say this

“Today we'll start with a vague idea, let the agent interview us, build a small version, try it ourselves, and make one improvement.”

## The teaching sequence

- Explain that an agent can work on files and try the result.
- Show a skill as a reusable workflow.
- Paste [the interview prompt](prompts/01-deep-interview.md).
- Approve the brief, then use [Week 1's build prompt](weeks/week-01/PROMPTS.md).
- Add one task, mark it complete and try an empty task.
- Record one observation and request one improvement.

Keep installation support from taking over the lesson. The minimum fallback is an approved brief and three concrete checks; finish setup and the actual build afterwards.
