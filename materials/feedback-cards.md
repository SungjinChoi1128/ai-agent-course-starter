# Feedback practice

Rewrite each statement with an observation, expected result and behavior to preserve.

1. “Make it nicer.”
   Example: I cannot distinguish completed tasks at a glance. Show them clearly while keeping them readable and reopenable.
2. “The filter is broken.”
   Example: After selecting Alex, Sam's task is still shown. Show only Alex's tasks; clearing the filter should show everyone.
3. “Make it smart.”
   Example: When I submit a blank task, explain what I need to enter. Do not add automatic text generation.
4. “It is too complicated.”
   Example: Adding a task requires three screens. Let me add one from the main screen while retaining optional owner entry.

Do not replace actual user observations with these examples when testing a real project.
