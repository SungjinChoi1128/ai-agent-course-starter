# Capstone ideas

Choose one useful task you can demonstrate with fake data. Extend an existing project when possible.

| Idea | Small useful version | Three possible checks | Non-goals |
| --- | --- | --- | --- |
| Meeting-action tracker | Enter tasks, mark complete, filter owner | Add; complete; filter and clear | Email, accounts, automatic extraction |
| Packing checklist | Add items and mark packed | Add; reject blank; remaining count | Travel booking, purchases |
| Reading tracker | Add title and reading status | Add; change status; filter | Scraping book sites, recommendations API |
| Workshop checklist | Tasks grouped by preparation stage | Add; group; complete | Payments, attendee personal data |
| Weekly actions report | Local JSON to draft Markdown | Correct count; repeat safely; reject invalid data | Automatic sending, production schedule |
| Lesson-resource index | Local links with labels and search | Add; search; empty result | Copying restricted material, public uploads |

Pick an intended user, one success moment and a clear boundary. A project with one well-verified workflow is enough.

Five-minute demo: user/problem (1 minute), live workflow (2), checks and edge case (1), limitations and next step (1).
