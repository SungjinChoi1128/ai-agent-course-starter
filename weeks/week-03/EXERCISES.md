# Week 3 exercises

Work in `workspace/projects/` or a new folder you own. Synthetic/personal-harmless data only.

## Hands-on exercise

1. Write a one-sentence user + problem.
2. Run the interview prompt; approve a brief with three checks and clear non-goals.
3. Ask Codex to build the smallest local version; open/run it yourself.
4. Try the happy path and one empty input; request one small fix if needed.
5. Commit. Push to a GitHub repository **you** own, or write what blocked the push.

## Minimum completion

Approved brief, working local utility, three checks attempted, GitHub URL or blocker note.

## Stretch exercise

Add a one-line README so a peer can open the project without you talking.

## Homework: 20–30 minutes

Finish the push if blocked, or improve one failed check. Bring the repo link next week.
