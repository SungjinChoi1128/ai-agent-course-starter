# Week 3 exercises

Work in your own project under `workspace/projects/`. Use synthetic data only. Copy blank worksheets from [templates](../../templates/README.md).

## Hands-on exercise

1. Ask the agent for a map of your actual project files, not a generic web-app diagram.
2. Identify the project root and the terminal's current folder.
3. Inspect whether your project has its own Git repository. If not, create one in that exact project folder and add appropriate ignore rules.
4. Inspect files before staging; create a local checkpoint using a learner-approved identity.
5. Inspect existing dependencies and explain one, or record that no external dependencies are needed.
6. Write the exact open/run/stop steps in a runbook.
7. Close the project process or file and restart it using only the runbook.
8. Exchange runbooks and correct missing directory, command or URL information.

## Minimum completion

A correct file map, one local checkpoint when identity is available, and a runbook that restarts the project. If commits are deferred, record why.

## Stretch exercise

Inspect the diff for a small change and explain it in plain language. Do not use reset or forced checkout to undo it.

## Homework: 20–30 minutes

Restart your project on another day without relying on the old chat. Record every missing step in the runbook and fix the instructions.

## Submit or show

File map, restart runbook, repository location and checkpoint reference or documented deferral.

You may demonstrate live or share a sanitized screenshot and short note. Do not upload raw chats, real credentials or private work materials.
