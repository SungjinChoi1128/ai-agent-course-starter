# Week 3 instructor notes

## Preparation

Confirm each learner has a GitHub login (or plan the “document the blocker” path). Have [prompts/01-deep-interview.md](../../prompts/01-deep-interview.md) ready. Keep ideas tiny: one screen, one list, or one form — not a multi-user product.

## Open

“Today you ship one small personal utility: interview, build, open it yourself, then put it on GitHub you control.”

## Facilitation

- Kill scope early. If the pitch needs login, payments, or a mobile app, cut to a local page or checklist.
- Keep interview and build as separate messages.
- For GitHub: learner-owned private repo is fine. Never push to the course instructor repo.
- If push fails (auth, org policy), celebrate the local commit + written blocker; finish push as homework.

## What to watch for

- Real client data in the app → replace with fictional examples.
- Agent invents a huge stack → ask for the smallest local version that passes the three checks.
- Clone of the course repo used as the student project → move work to `workspace/projects/` or a new repo.

## Debrief

“Show the result, not the chat.” Collect brief, demo, and repo link or blocker.
