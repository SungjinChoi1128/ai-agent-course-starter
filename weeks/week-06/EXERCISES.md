# Week 6 exercises

## Hands-on exercise

1. Choose: real service (read-only) **or** local fake folder stand-in.
2. Write allow list (what it may read) and deny list (send/delete/write/share).
3. Connect with least access; refuse extra scopes.
4. Perform one successful read; save evidence.
5. Write how to disconnect/revoke access.

## Minimum completion

Read-only (or stand-in) connection + read evidence + trust boundary note.

## Stretch exercise

Compare two permission prompts and explain which is safer and why.

## Homework: 20–30 minutes

Revoke a practice permission (or document how you would), and note one scope you will never grant this agent.
