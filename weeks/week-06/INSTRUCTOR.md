# Week 6 instructor notes

## Preparation

Decide which services you will allow in class. Default recommendation: local folder of fake files if anyone is unsure. If using Gmail/Drive/Calendar MCP, insist read-only and personal/test accounts only — never client mailboxes.

## Open

“Today we touch a real service — carefully. Read-only. Least access. If login feels risky, use a local fake folder and practice the same trust habits.”

## Facilitation

- Anyone pasting secrets into chat → stop, rotate if needed, switch to local stand-in.
- Celebrate refused permissions as success.
- Do not require a paid SaaS. Local stand-in fully satisfies the week's learning goal if documented honestly.

## Debrief

Collect allow/deny lists and one read proof. No write demos.
