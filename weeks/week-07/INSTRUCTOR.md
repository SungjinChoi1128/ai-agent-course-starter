# Week 7 instructor notes

## Preparation

Ban live “send to everyone” demos. Drafts written to a local file are the classroom default. Have dirty/duplicate fixtures available if useful (`materials/data/dirty-actions.json`).

## Open

“Automation without a stop switch is a future incident. Today: run twice cleanly, and prove you can stop it.”

## Facilitation

- Dry run before any schedule.
- Duplicate rule must be explicit (e.g. skip if same id/title already in output).
- If someone wants cron/schedule UI, fine — but class success is two manual runs + stop switch.

## Debrief

Evidence of two runs and a halted run beats a fancy schedule.
