# Week 7 exercises

Work in your own project under `workspace/projects/`. Use synthetic data only. Copy blank worksheets from [templates](../../templates/README.md).

## Hands-on exercise

1. Select one actual change and inspect its diff or before/after file comparison.
2. Write the user-visible effect and one plausible regression.
3. Run existing automated checks and personally perform a normal and an edge-case action.
4. Label each release claim with the evidence supporting it.
5. Review all safety cards and choose proceed, narrow/confirm, or stop with a reason.
6. Inspect the project for accidentally included data, secret files and unnecessary permissions without printing secret values.
7. Complete the release checklist and state known limitations.
8. Ask a peer for a go/no-go decision. Resolve one evidence gap or record it clearly.

## Minimum completion

A completed verification checklist and a justified release decision. Actual publishing is optional and not part of this lesson.

## Stretch exercise

Ask the agent to identify a missing test for a meaningful boundary, then add and run it using existing tooling. Preserve failing tests until their cause is resolved.

## Homework: 20–30 minutes

Audit the capstone idea and project. Remove real-world sensitive inputs from the planned scope, identify two failure cases and bring a release checklist draft.

## Submit or show

A diff explanation, actual test/manual results, a safety-card response and a release decision with limitations.

You may demonstrate live or share a sanitized screenshot and short note. Do not upload raw chats, real credentials or private work materials.
