# Week 7 exercises

## Hands-on exercise

1. Choose a weekly job and its reader.
2. Fill the automation contract including duplicate rule and stop switch.
3. Build with dry-run / local draft output first.
4. Run twice; confirm no duplicates.
5. Activate the stop switch (or feed bad input) and confirm it does not proceed.

## Minimum completion

Contract + two clean runs + stop-switch proof.

## Stretch exercise

Add a simple schedule note (when it would run) without enabling unattended sends.

## Homework: 20–30 minutes

Tighten the duplicate rule with one more edge case. Keep outputs local.
