# Week 4 instructor notes

## Preparation

Ask learners to bring Week 3 projects. Prepare feedback cards if useful (`materials/feedback-cards.md`). Save a known-good copy before anyone “improves” everything at once.

## Open

“The agent saying ‘done’ is not proof. Today you run three checks yourself, turn one failure into a fix, and recheck.”

## Facilitation

- Prefer observable checks (“adding an empty item shows a clear message”) over adjectives (“feels nice”).
- During silent user test, author may not coach until the user finishes the attempt.
- Block large rewrites: smallest fix that addresses the failed check.

## Debrief

Collect inspection evidence, not pride in how much code changed.
