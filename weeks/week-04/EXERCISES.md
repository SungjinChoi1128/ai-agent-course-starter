# Week 4 exercises

## Hands-on exercise

1. Restart your Week 3 app; record one baseline success.
2. Write three checks a peer can try without explanation.
3. Peer runs the checks; you stay silent; note expected vs actual.
4. Choose one failure or unclear result; ask Codex for the smallest fix.
5. Recheck the failure and one old success.

## Minimum completion

Three checks with results + one verified fix (or a clear blocker with evidence).

## Stretch exercise

Add a fourth edge-case check without expanding features.

## Homework: 20–30 minutes

Polish the inspection log. If a check still fails, write the next discriminating question you will ask Codex.
