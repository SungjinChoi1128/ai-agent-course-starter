# Week 5 exercises

## Hands-on exercise

1. Confirm NotebookLM MCP (or another approved live MCP) tools appear in Codex.
2. Write a short skill that asks 2–3 questions and produces a one-line note text.
3. Instruct the agent to use `add_note` (or `search_notes`) with that text.
4. Open `the live result (notebook counts, insight file, or equivalent)` and confirm the change.
5. Have a peer run the same workflow once.

## Minimum completion

Skill file + MCP tool call evidence + visible file change.

## Stretch exercise

Skill chooses between `add_note` and `search_notes` based on the user's answer.

## Homework: 20–30 minutes

Tighten the skill wording so a peer needs no coaching. Bring one confusion you removed.
