# Week 5: Skill + MCP workflow

Skill gathers intent; MCP does the live action. 90 minutes, four learners.

## Expected outcomes

- Write a short reusable skill (playbook) that interviews or structures a request.
- Call an MCP tool (NotebookLM or another approved live MCP) to perform the live action.
- Show one combined run: skill output → MCP tool call → visible result in `the live result (notebook counts, insight file, or equivalent)` (or equivalent).

## Before class

Bring Week 2 NotebookLM MCP (or another approved live MCP) (rebuild if needed — still local, no Gmail). Have skill file location from Setup ready.

## 90-minute agenda

| Time | Minutes | Activity | What learners do |
| --- | --- | --- | --- |
| 0–10 | 10 | Recall | Skill vs MCP in one sentence each; confirm MCP still connects |
| 10–25 | 15 | Design the chain | Decide: skill asks 2–3 questions → MCP live action on the notebook or tool |
| 25–55 | 30 | Build | Create/update skill file; keep MCP separate; test the chain |
| 55–70 | 15 | Prove | Full run without author coaching; open the resulting evidence file |
| 70–82 | 12 | Peer try | Peer follows skill + uses MCP; note confusion |
| 82–90 | 8 | Share | Show combined mini-automation and one limitation |
