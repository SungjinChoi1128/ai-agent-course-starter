# Week 1: Your first useful build

Coding agents, skills and a Deep Interview. 90 minutes, three learners.

## Expected outcomes

- Explain that an agent can inspect files, make changes, run work and check results within its available permissions.
- Describe a skill as a reusable set of workflow instructions, sometimes with supporting files.
- Turn one vague idea into an approved brief, a first version and one inspected improvement.

## Before class

Complete SETUP.md before class. Open the sample meeting notes and demo brief. Have one prepared local tracker available if the live build stalls.

## 90-minute agenda

| Time | Minutes | Activity | What learners do |
| --- | --- | --- | --- |
| 0–10 | 10 | Minimal mental model | Show a chat answer and an agent-created file; learners name the difference. |
| 10–20 | 10 | Skills and light safety | Open the verified SKILL.md; explain instruction reuse and review one install command. |
| 20–35 | 15 | Live Deep Interview | Use the classroom prompt with the vague meeting-actions idea; learners predict and answer questions. |
| 35–45 | 10 | Learner interview and brief | Each learner runs a short interview and approves three checks. |
| 45–65 | 20 | First build | Ask for the smallest local version and open the result. |
| 65–80 | 15 | Inspect and improve | Try a normal action and an empty input, then make one small change; rotate peer roles. |
| 80–87 | 7 | Mistake and recovery | Show an unexpected result, describe expected versus actual, and recheck a correction. |
| 87–90 | 3 | Exit and homework | Each learner names a changed assumption and one remaining limitation. |
