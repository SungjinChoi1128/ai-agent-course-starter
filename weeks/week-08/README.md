# Week 8: Capstone demo day

Own tool demoed to peers with handover notes; peer can use it silent. 90 minutes, four learners.

## Expected outcomes

- Deliver one bounded project that helps a specific user (skills, MCP, and/or automation from prior weeks).
- Demonstrate three success checks and one edge case.
- Hand over enough instructions that a peer can run it with the author silent.

## Before class

Arrive with a scoped idea, working pieces from earlier weeks, and a draft brief. Use [materials/capstone-ideas.md](../../materials/capstone-ideas.md) and [templates/handover.md](../../templates/handover.md). New paid integrations are out of scope unless already working.

## 90-minute agenda

| Time | Minutes | Activity | What learners do |
| --- | --- | --- | --- |
| 0–10 | 10 | Pitch and scope | One-minute pitch; agree smallest demoable result |
| 10–20 | 10 | Acceptance | Finalise 3 checks, 1 edge case, non-goals |
| 20–45 | 25 | Build or finish | Remaining bounded work; halfway checkpoint |
| 45–60 | 15 | Peer test | Author silent; peer follows handover draft |
| 60–72 | 12 | Correct | Highest-impact fix; rerun checks |
| 72–87 | 15 | Demos | ~4 minutes each: problem, result, evidence, limitation |
| 87–90 | 3 | Next step | Save handover; name one next improvement |
