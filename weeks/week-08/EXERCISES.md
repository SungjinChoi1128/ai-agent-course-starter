# Week 8 exercises

## Hands-on exercise

1. Write a one-minute pitch and freeze scope.
2. Lock three checks + one edge case + non-goals.
3. Finish only what the demo needs.
4. Peer runs from your handover while you stay silent; note gaps.
5. Fix the highest-impact gap; demo with evidence and one limitation.

## Minimum completion

Working demo + peer-silent run (or documented gap) + handover file.

## Stretch exercise

Add a 60-second “what MCP vs skill did here” explanation to the handover.

## Homework: after class

Optional polish only. Do not expand scope. Share sanitized demo evidence if the cohort collects it.
