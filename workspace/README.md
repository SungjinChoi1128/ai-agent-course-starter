# Your practice area

The bootstrap creates `projects/` and `notes/` here. Their contents are ignored by the course repository so that a routine course commit does not publish your work.

Start each build in `workspace/projects/my-first-agent-project/`. Save briefs and inspection logs in that project. Course handouts stay in the top-level weeks and materials folders.

Ignored is not secret or backed up. The agent can still read files in its allowed workspace, and ignored files remain on disk.

In Week 3, initialise a separate Git repository inside your project, with its own ignore rules and local identity settings. A nested project repository is independent of the outer course repo. Always check the repository root before committing. Project commits do not enter the outer course history automatically.

If you later want to publish a project, create a separate repository you own, inspect its files and history, and use its remote. Never push to the instructor's course remote as part of a student exercise.
